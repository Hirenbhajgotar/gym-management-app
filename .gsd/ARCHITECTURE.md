## Components

### 3. Biometric Attendance & Access Control Engine
- **Purpose:** Hardware-agnostic communication with physical biometric terminals (facial recognition, fingerprint scanners, door controllers) supporting real-time unlock and offline sync.
- **Location:** `app/Biometrics/`, `app/Models/AdmsDeviceCommand.php`, `app/Http/Controllers/Api/AdmsController.php`, `app/Http/Controllers/Api/HikvisionAdmsController.php`

  - **Instant Webhook Door Relay** (`/api/v1/biometric/webhook/{token}`): Sub-second door unlock triggers with anti-passback enforcement (`anti_passback_window_seconds`).
  - **Remote FIFO Command Queue**: `AdmsDeviceCommand` model handles asynchronous user credential provisioning (`DATA UPDATE USERPIN`), deletion (`DATA DELETE user`), and device reboots with idempotency keys.

## Data Flow

### 1. Biometric Check-In & Door Unlock Flow
1. **Edge Punch:** Member scans finger/face at terminal.
2. **Push/Webhook:** Device hits `/api/v1/biometric/webhook/{token}` (instant relay) or `/api/iclock/cdata` (ADMS `ATTLOG`).
3. **Authentication:** Request authenticated via device token or PBKDF2 communication key (`AuthenticateAdmsDevice`).
4. **Member Lookup:** System resolves `GymMember` matching biometric PIN within the terminal's `gym_id`.
5. **Eligibility Verification:** Checks membership status (`Active`), freeze status, and anti-passback window (60s).
6. **Attendance & Relay:** If valid, records attendance in `attendances` table, dispatches door unlock signal to door controller, and fires Reverb event. If expired or unapproved, logs denial in `door_events`.

### 2. WhatsApp Broadcast Campaign Flow
1. **Targeting:** Gym owner selects member segment (e.g. expiring in 7 days, inactive 14+ days) in Filament Admin.
2. **Credit Check:** `WhatsAppBillingService` verifies tenant's `WhatsAppMessageCredit` balance.
3. **Orchestration:** `WhatsAppBroadcast` is created, segmented into chunks of recipients, and dispatched via `SendBroadcastJob`.
4. **Queue Worker:** Worker processes chunk, resolves template variables, calls `MetaWhatsAppProvider::sendMessage()`, and logs delivery ID.
5. **Webhook Updates:** Meta sends delivery status (`sent`, `delivered`, `read`, `failed`) to `/api/webhooks/whatsapp/templates-status` or `/messages`, updating `WhatsAppBroadcastRecipient` status.

### 3. Member Freeze & Expiry Extension Flow
1. **Initiation:** Operator triggers freeze action on `GymMemberResource`.
2. **Validation:** Checks gym freeze thresholds (`min_freeze_days`, `max_freeze_days`) and active plan limits.
3. **Lock & Audit:** Acquires database row lock (`lockForUpdate`), updates `GymMember` freeze dates, logs event via Spatie Activitylog, and sends email notification.
4. **Hardware Purge / Unfreeze:** If freeze is indefinite or exceeds cutoff, queues `DATA DELETE user` on biometric terminals.
5. **Reconciliation:** When member returns early or unfreezes, `MemberFreezeService` calculates actual frozen days, extends `membership_end` date, updates `member_payments` quietly, and re-provisions biometric credentials via `AdmsDeviceCommand`.

## Conventions

**Architecture & Framework Rules:**
- **Strict Typing:** Every PHP file must declare `declare(strict_types=1);` at the top.
- **PHP 8.2+ Patterns:** Constructor property promotion required in all services and commands.
- **Model Attribute Casting:** Use `protected function casts(): array` instead of deprecated `$casts` property.
- **Form Requests:** Use dedicated Form Request classes for validation; do not place inline validation in HTTP controllers.
- **Filament Resources:** Rely on static `make()` initializers and avoid raw database queries (`DB::table`); prefer typed Eloquent relationships with eager loading.
- **Frontend / Components:** Use Volt single-file components for interactive widgets, Flux UI Free components (`<flux:*>`) for controls, and Tailwind CSS v4 utilities (`gap-*` instead of outer margins).
- **Testing:** Standardized on PHPUnit 11 (no Pest syntax). Tests must run against `gym_app_test` using `composer test` or `docker-compose exec app php artisan test`.
